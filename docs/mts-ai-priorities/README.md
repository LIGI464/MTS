# Пульт координатора · приоритеты ИИ

Пакет промтов для `LIGI464/MTS`. Исходное приложение — ветка `codex/dashboard-review` на проверенном коммите `a16db4ae5a087000ddb81e81df30ba4634eca71a`. В нём уже есть сводка, шесть блоков очередей, журнал «События», ИИ-анализ отдельного инцидента и приёмка D40. Новая лента собирает заявки, которые стоит выполнить сейчас, и объясняет их порядок. В каждой карточке очереди под названием появляется короткое описание проблемы для оператора.

## Стартовое сообщение

> Открой `LIGI464/MTS` на ветке `docs/ai-priority-feed-prompts`. Прочитай `docs/mts-ai-priorities/README.md` и выполни P00 → P10 → P20 → P30 → P40 в одной отдельной рабочей ветке от коммита пакета. Используй PNG-референсы, локальную тему и шрифты МТС, демоданные репозитория. Под названием каждой заявки в очередях показывай короткое описание от ИИ обычным текстом без пометки об авторстве. Удали всплывающие карточки событий с пульта. Проверь, что журнал «События» продолжает работать по действующим правилам. После каждого блока покажи результат и скриншоты, сообщи SHA и дождись моего подтверждения. В конце приложи отчёт P40.

## Блоки

| Блок | Задание | Результат |
| --- | --- | --- |
| [P00](P00-start.md) | База и запуск | Проверенный SHA, рабочая ветка, исходные кадры |
| [P10](P10-ranking.md) | Расчёт приоритетов и описаний | Общая ранжированная выдача с проверяемыми обоснованиями и краткие описания заявок |
| [P20](P20-navigation.md) | Карточки и переходы | Описания в очередях, длительная подсветка целей, раскрытие SLA, критическая сводка и удаление всплывающих карточек |
| [P30](P30-feed.md) | Лента «В работу сейчас» | Карточки рекомендаций и переход с открытием «Подробнее» |
| [P40](P40-acceptance.md) | Приёмка | Проверки, контрольные кадры и итоговый SHA |

При продолжении в другом чате укажи рабочую ветку, последний принятый SHA и следующий блок. Для серверных проверок используй временную копию демоэкспорта и управляемый ответ провайдера.
