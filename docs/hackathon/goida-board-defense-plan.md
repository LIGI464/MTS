# Goida-board · план защиты GoidaCode

**Цель — около 4 минут.** На слайдах 4–7 запустите видео одним нажатием на кадр и говорите поверх записи. Курсор останавливается перед кликом, выбранный элемент обводится и приближается. Дайте жюри увидеть результат, затем перейдите дальше по подсказке справа.
