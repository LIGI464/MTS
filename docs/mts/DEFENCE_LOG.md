## Правка после слияния

`@mts/api` зависит от `@fastify/static` `10.1.12`. Версия зафиксирована `npm install`, lockfile не правился руками. В `apps/api/src/http/index.ts` `setHeaders` принимает `FastifyReply` и ставит `Cache-Control` через `reply.header()`.

На Windows `rename` поверх живого JSON иногда возвращает `EPERM`, пока опрос файла его читает. `atomicWrite` повторяет замену при `EPERM`, `EBUSY` и `EACCES`. Первый полный `npm test` без этого упал на двух тестах API; после правки suite проходит.

- Демо-даты сдвигаются от момента первого создания каталога. На защите это синтетический набор из пяти записей, не выгрузка на 44 записи.

- Битый или отсутствующий JSON не очищает доску: остаётся последний годный снимок и баннер устаревшего источника.
- На Windows замена живого файла может кратко получать `EPERM`; запись повторяется.
- `data/runtime`, `.env`, сборка `dist` и секреты в Git не входят.
