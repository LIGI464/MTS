# T24 · Astra A · Безопасный маршрут анализа

Ты продолжаешь `feat/api`. Работай в `apps/api/src/analysis/**` и тестах маршрута. Прочитай [контракт](../CONTRACT.md). Пакет `@mts/analysis` уже экспортирует `createAnalyzer`. В этой задаче подключи его к HTTP, жизненному циклу и кешу.

1. Из `analysis/index.ts` экспортируй `registerAnalysisRoutes(app, context)`. Подготовь анализатор из env по типу `AnalyzerConfig`. Поддержи `rules` по умолчанию и `live`, когда есть `CODEX_SALE_API_KEY`, `CODEX_SALE_MODEL` и `MTS_OPERATOR_TOKEN`. Значения из браузера используются как токен оператора, ключ провайдера и base URL берутся из серверного окружения.
2. В POST `/api/v1/incidents/:id/analysis` найди запись в свежем снимке. Верни `404` при неизвестном ID. При переданном неверном Bearer верни `403`. Без токена вызови правила. С действующим токеном и настроенным live выставь `useLive=true`. Передай в `prepare` инцидент, приватное описание, историю из того же снимка и `serverNow`.
3. Сохраняй до 128 успешных результатов в памяти на 10 минут. Ключ включает `prepared.key` и запрошенный режим. Идущие одновременно одинаковые запросы делят один Promise. Резервный ответ по ошибке модели сохраняй до 30 секунд. Чисти кеш на `demo.reset`, включая невозможность записать старый незавершённый ответ после сброса.
4. Лимит внешних вызовов · до двух одновременно и восьми в минуту на стенд. Проверяй только перед фактическим вызовом провайдера, после поиска кеша и уже выполняющегося запроса. При исчерпании отдай `429` с нормальным русским текстом. Запрос анализа работает асинхронно отдельным обработчиком.
5. Валидируй результат `AnalysisResultSchema` и совпадение ID и версии. Ошибки внешней связи превращаются в локальные правила через пакет анализа. В логе остаются категория сбоя и время, без содержания файла, ответов модели и заголовков. При регистрации подписчика привяжи отписку к закрытию Fastify.
6. Для тестов подставь мок анализатора. Утверди, что без токена вызов live отсутствует, повтор не вызывает вторую оплату, неизвестный ID даёт `404`, неверный токен `403`, смена версии и reset сбрасывают кеш. Пока анализ ждёт, SSE продолжает публиковать кадры.

**Приёмка.** `npm test -- apps/api/tests`, `npm run check` и `npm run build`. Режим `rules` полностью работает с заглушкой B00. Реальная проверка совместно с B30 проводится в T51 и T52.
