# B00 · Агенту, который создаёт основу

Ты интегратор проекта goida-code. Работай в `setup/base` от текущего `main`. Результат — запускаемый каркас, один lockfile, согласованные типы и фикстуры для одновременного старта трёх исполнителей.

Прочитай [ТЗ](../TZ.md) и [контракт v1](../CONTRACT.md). Выполни [T01](T01-workspaces.md), затем [T02](T02-contracts.md). В `T01` создай workspaces и минимальные точки входа. В `T02` опубликуй Zod-схемы, типы, функции работы с датами и фикстуры. Сохрани стабильные пути и сигнатуры, которые указаны в индивидуальных промтах.

Доведи основу до состояния, где Cursor видит интерфейс с mock, API компилируется с заглушками функций для следующих блоков, а `@mts/analysis` уже импортируется и возвращает тестовый результат по правилам. Подготовь `.env.example` и команды из контракта. Отдельные точки входа B10, B20 и B30 должны собираться без исходников чужой ветки.

Выполни `npm ci`, `npm run prep:local`, `npm run check`, `npm test`, `npm run build` и проверь `npm run dev:web`. Результаты и точный SHA укажи в PR. После его слияния передай SHA трём исполнителям из [карты работ](../../../README.md). Слиянием управляет один интегратор.
