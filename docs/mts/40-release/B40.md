# B40 · Astra 6.2 B, сборка и VPS

Ты отвечаешь за поставку дашборда. Прочитай [ТЗ](../TZ.md) и [контракт](../CONTRACT.md). Возьми [T41](T41-package.md) в `feat/deploy` после B00. Работай с Git. Сборка должна запускать тот же Fastify, который обслуживает Web, REST и SSE. Постоянные данные хранятся в отдельном томе.

Когда интегратор выдаст прошедший проверки SHA T51, передай [T42](T42-vps.md) агенту или оператору с разрешённым доступом к VPS. Если облачная сессия подключена только к GitHub, её результат — ветка с Docker, CI и инструкцией. Операции на хосте выполняются из отдельной сессии. Домен, ключ модели, операторский токен и файл выгрузки задаются вне репозитория владельцем стенда.

**Приёмка.** Локальная сборка образа и `/healthz` подтверждены. Для рабочего VPS укажи точный SHA, публичный HTTPS-адрес, результат получения SSE и способ отката на предыдущий образ. В журнале T52 раздели фактические проверки и ещё открытые внешние параметры.
