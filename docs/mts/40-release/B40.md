# B40 · Сборка и развёртывание

Astra 6.2 B в облаке выполняет [T41](T41-package.md) в `feat/deploy` после B00. Входы · GitHub, [ТЗ](../TZ.md) и [контракт](../CONTRACT.md). Выход · PR с Docker Compose, CI, инструкцией и доступными результатами тестов сборки. Сборка запускает тот же Fastify, который обслуживает Web, REST и SSE. Постоянные данные хранятся в отдельном томе.

Исполнитель 2 выполняет [T42](T42-vps.md) со своего компьютера после получения проверенного SHA T51. Он использует именной SSH-доступ. Владелец VPS выполняет шаги, для которых требуются системные полномочия, а владелец DNS направляет поддомен на сервер. Ключ модели, операторский токен и выгрузка задаются на VPS вне Git. [Распределение доступа](../ACCESS.md).

**Приёмка.** Для T41 укажи результат доступных проверок сборки. В T42 подтвердите запуск образа и `/healthz`. Для работающего VPS укажите точный SHA, публичный HTTPS-адрес, результат получения SSE и способ отката на предыдущий образ. В журнале T52 раздели фактические проверки и ещё открытые внешние параметры.
