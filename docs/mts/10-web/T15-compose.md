# T15 · Cursor · Собери рабочий экран из четырёх веток

Ты ведущий Cursor на ветке `feat/web`. Слей коммиты T11–T14, основанные на одном SHA B00. Читай [ТЗ](../TZ.md) и [контракт](../CONTRACT.md). Работай в `apps/web/src/App.tsx`, `src/main.tsx` и `src/styles/**`. Исправления внутри отдельной папки обсуждай с владельцем соответствующей задачи.

1. В `main.tsx` создай один `QueryClient` и `QueryClientProvider`. В `App.tsx` подключи `useDashboard`, `AppShell`, `IncidentBoard` и `DemoControls`. Задай базовые цвета и размеры из ТЗ через CSS-переменные. Основной экран · «Пульт координатора», рядом тихий индикатор «Данные актуальны», «Переподключение», «Файл временно недоступен» либо «Демонстрационные данные».
2. Отрисуй доску при наличии снимка, скелет при первом запросе и пустой экран при недоступности данных. `source.status=stale` показывает баннер и сохраняет карточки. Состояния клиента и файла различаются. Выведи небольшую ленту событий и тосты из `newNotices`. У тоста доступны ID и текст события, закрытие использует `dismissNotice`. При `critical.resolved` запиши событие в ленту и покажи зелёный тост «Критический инцидент решён».
3. Сделай одну панель деталей Radix Dialog с заголовком, временем, статусом, исполнителем, описанием и `AnalysisPanel`. Выбранный ID живёт в `App`, актуальная запись берётся из последнего снимка. «В ITSM» ведёт по `itsmUrl`. При пустом адресе виден текст «Ссылка ITSM не настроена». Отдельное действие «История» открывает вкладку панели со списком решённых, закрытых, исследуемых и неизвестных состояний.
4. `operatorToken` хранится в React state. Вставь `DemoControls` в `footerSlot`, `onReset` вызывает `resetDemo`. При `demo.reset` закрой панель деталей и очисти выбранный результат. В mock добавь в конец страницы компактные кнопки шагов, которых нет при `VITE_DATA_MODE=api`.
5. Проведи mock-сценарий по всем переходам. Отображение уведомлений, таймера, 4 групп, меню и сброса должно подтверждаться через обычный браузер. Если API уже слит, повтори на `npm run dev`. Снимки экранов держи в отчёте проверки, сборка проекта должна обходиться без внешних визуальных ассетов.

**Проверка.** `npm ci`, `npm run prep:local`, `npm run check`, `npm test`, `npm run build`. В PR укажи результат для `1440×900` и `390×844`, опиши все проверенные переходы и базовый SHA.
