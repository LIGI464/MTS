# T11 · Cursor · Портальная оболочка и шторки

Ты отвечаешь за навигацию и оболочку Пульта координатора. Ветка `feat/web-shell` от SHA B00. Меняй только `apps/web/src/shell/**`. Прочитай раздел «Интерфейс» в [ТЗ](../TZ.md). Используй React, Radix Dialog/Accordion, CSS Modules и Lucide. Референс ролей навигации находится в конце задания.

Экспортируй `AppShell({ children, healthBadge, footerSlot })` из `src/shell/index.ts`. Все три значения — `ReactNode`. `children` занимает рабочую область. `healthBadge` виден рядом с заголовком. `footerSlot` рендерится после всех нижних разделов в потоке документа.

## Собери три поверхности

1. Верхняя узкая часть показывает «goida-code», «Кейс МТС», сегменты «Частным лицам», «Бизнесу», «Ещё», регион «Ростовская область», «Оплата» и «Вход». У сегментов и региона есть раскрывающаяся панель. У «Ещё» пункты «О компании», «Госзаказчикам», «Партнёрам», «Инвесторам». «Оплата» и «Вход» открывают короткую демонстрационную панель, из которой можно перейти на публичную витрину. Внутренних форм оплаты или входа нет.
2. Вторая строка включает «Мобильная связь», «Для дома», «Оплата и финансы», «Интернет-магазин», «Сервисы», «Поддержка». Добавь для каждого раздела 2–4 коротких представительных пункта. Например, для связи · тарифы, eSIM, роуминг. Для дома · интернет и ТВ. Для услуг · развлекательные и цифровые сервисы. Данные меню хранятся в одном `nav.ts`, оформление и тексты самостоятельные. При известном проверенном адресе используй внешний линк, иначе подпиши пункт «Демо».
3. Внизу размести обычный футер с разделами «Связь и дом», «Сервисы», «Поддержка», «Документы», «О проекте» и слот служебных действий после него. На узком экране доступна нижняя выдвижная панель с этими группами. На широком экране нижние группы раскрываются в футере. Отдельное действие «Информация о сайте» открывает компактную нижнюю шторку со сведениями о прототипе и кнопкой «Понятно». Панель на телефоне появляется по кнопке внизу, а её закрытие возвращает фокус к этой кнопке.

## Реализация

Выдели `PortalHeader`, `PortalFooter` и один переиспользуемый `NavigationDialog`. Единое состояние `openMenu` допускает одну открытую шторку. Закрытие по Esc, клику вне содержимого и явной кнопке. Radix держит фокус внутри модальной панели. Короткая шапка и тонкая линия отделения, самостоятельная композиция с графитовым текстом и бордовым активным пунктом. На настольном первом экране суммарная навигация занимает до `112 px`. Футер идёт после рабочей области. Бери из источника названия общих категорий и роли меню. В оболочке видна подпись «goida-code · Кейс МТС».

**Приёмка.** На `1440×900` шапка оставляет место четырём группам. На `390×844` работают верхняя и нижняя шторки, горизонтальной прокрутки нет. Tab, Shift+Tab, Esc и возврат фокуса проверены. Выполни `npm run prep:local`, `npm run check` и `npm run build`. Сделай коммит своей ветки.
