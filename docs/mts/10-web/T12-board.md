# T12 · Cursor · Четыре группы, карточки и таймер

Ты реализуешь основную доску. Ветка `feat/web-board` от SHA B00. Твой путь · `apps/web/src/board/**`. Прочитай [ТЗ](../TZ.md) и правила групп и SLA в [контракте](../CONTRACT.md).

Экспортируй `IncidentBoard({ snapshot, nowMs, onInspect })` из `src/board/index.ts`. Типы · `Snapshot`, `number` и `(id: string) => void`. Доска получает готовые группы, сопоставляет строки с Map по ID. Для карточки внутри группы React key равен ID, для аналитики и деталей сохраняется единый ID между группами.

1. Сделай два столбца на desktop. Первый ряд · «Критические» и «У координаторов», второй · «Высокий приоритет» и «Исследование». На узком экране группы идут вертикально в том же порядке. Шапка каждой группы включает название и количество. В пустой группе короткое значение «Нет инцидентов». Для длинных очередей используй прокручиваемую область внутри секции на широком экране, чтобы одна группа не выталкивала остальные.
2. Карточка включает заголовок и ID, продукт и сервис, время регистрации, имя исполнителя и команду, состояние и срок. При нехватке места перенос или однострочный ellipsis с доступным полным названием. `null` обрабатывай явно. Исследование показывает «Решён · исследование» с датой при наличии. Рабочий таймер показывает длительность и статус, использует `getSlaState`. Дату срока дай в `title` или доступной подсказке, время печатай в `Europe/Moscow`. Добавь `font-variant-numeric: tabular-nums`.
3. Красный текст и тонкая рамка для критических и просроченных, янтарный знак и текст «Срок близко» для `near`. Обычные и исследовательские карточки спокойные. Таймер всех карточек берёт единый `nowMs` из props. Годность карточки менять на тике, порядок и фокус сохранять. Иконки поддерживают текстовые метки.
4. `title` и действие «Детали» выбирают `onInspect(id)`. Внешняя кнопка «В ITSM» доступна на карточке при `itsmUrl` и открывает отдельную вкладку через `rel="noopener noreferrer"`. В режиме без URL карточка остаётся интерактивной через детали.
5. Добавь unit-тесты для преобразования времени (отрицательное, граница, часы, дни, `null`). Проверь одну и ту же карточку в двух группах на фикстуре `assign`. При `resolve` она уходит из активных групп. История находится в T15. Для отсутствующего в Map ID пропускай ссылку на запись и сохраняй разметку доски.

**Приёмка.** На `1440×900` видны 4 заголовка и первый ряд каждой непустой группы. В `390×844` нет горизонтального скролла, данные читаемы. Таймер не объявляется скринридеру каждую секунду. Прогони `npm test -- apps/web/src/board`, `npm run check` и `npm run build`. Передай коммит и результаты.
