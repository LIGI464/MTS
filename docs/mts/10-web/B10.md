# B10 · Cursor, интерфейс Пульта координатора

Ты ведущий фронтенд-агент команды goida-code. Возьми общий SHA B00 из `main` и создай `feat/web`. Прочитай [ТЗ](../TZ.md) и [контракт](../CONTRACT.md). Весь Web должен собираться на mock, пока Astra A пишет API. Используй только пути `apps/web/src/**` и тесты этого workspace.

Выдай отдельным агентам Cursor полный текст [T11](T11-shell.md), [T12](T12-board.md), [T13](T13-client.md) и [T14](T14-actions.md). Каждый стартует в отдельном Git worktree от одного SHA.

| Задача | Ветка | Область |
|---|---|---|
| T11 | `feat/web-shell` | `src/shell/**` |
| T12 | `feat/web-board` | `src/board/**` |
| T13 | `feat/web-client` | `src/data/**` |
| T14 | `feat/web-actions` | `src/analysis/**` и `src/demo/**` |
| T15 | `feat/web` | `src/App.tsx`, `src/main.tsx`, `src/styles/**` |

Пример из корня Git. Повтори `git worktree add` для остальных имён из таблицы, базовый SHA тот же.

```bash
git fetch origin
git worktree add -b feat/web-shell ../mts-ui-shell origin/main
```

Установи зависимости в каждом worktree через `npm ci`, собери общие пакеты `npm run prep:local`. Для одновременного визуального просмотра используй свои порты Vite через workspace-команду. Каждый агент сдаёт отдельный коммит и сообщает фактически проверенный сценарий. Слей результаты в `feat/web` и выполни [T15](T15-compose.md).

**Приёмка ветки.** Четыре группы и карточки видны с первого взгляда. Все шторки открываются и закрываются. Mock воспроизводит четыре события с обновлением очереди и таймера. Анализ и сброс доступны по своим действиям. В верхней рабочей части сброс отсутствует. `npm run check`, `npm test`, `npm run build` проходят. Отчитайся SHA и результатами блока.
