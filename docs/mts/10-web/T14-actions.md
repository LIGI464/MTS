# T14 · Cursor · Анализ и скрытые служебные действия

Ты делаешь интерфейсы анализа и сброса. Ветка `feat/web-actions` от SHA B00. Пути · `apps/web/src/analysis/**` и `apps/web/src/demo/**`. Прочитай [контракт](../CONTRACT.md). Сетевые вызовы передаются функциями через props.

- Из `src/analysis/index.ts` экспортируй `AnalysisPanel({ incident, runAnalysis, operatorToken })`. Типы · `Incident`, функция `(id: string, token?: string) => Promise<AnalysisResult>`, `string | undefined`. Панель содержит кнопку «ИИ-анализ», загрузку, результат и текст ошибки с повтором. Покажи краткое описание, предлагаемую команду или «Команда не определена», обоснование, уровень риска и факторы. `llm` подписывай «codex.sale», `rules` — «Локальные правила». Фактор срока объясняй словами. Для `not_applicable` используй «Не применяется» с причиной из ответа.
- Панель держит результат для текущих `incident.id` и `incident.version`. Смена записи или версии инвалидирует запрос. Проверяй ID и версию в ответе. Двойной клик во время ожидания не даёт второй POST. Блокировка распространяется на действие анализа. Карточки, таймер и навигация остаются активны.
- Из `src/demo/index.ts` экспортируй `DemoControls({ enabled, liveAnalysis, operatorToken, onOperatorToken, onReset })`. Типы · два `boolean`, `string | undefined`, `(token: string | undefined) => void` и `(token: string) => Promise<Snapshot>`. Компонент возвращает `null`, когда обе возможности выключены. В остальных случаях это закрытый по умолчанию `details` с `summary` «Служебное». Внутри поле операторского токена типа password. Сохраняй его только через callback в памяти вкладки. Предусмотри действие «Очистить». При `enabled` показывай кнопку «Сбросить демо» внутри шторки и подтверждение в Radix Dialog. По успеху сообщи «Набор восстановлен», по ошибке выведи понятный текст. Выключай повторное действие во время запроса.
- Покрой чистые переходы состояния при устаревшем ответе и отказе токена через Vitest. Итоговую доступность сброса и метку резервного источника проверь в интеграционном сценарии. Полноэкранная интеграция панели — T15. Русские подписи пишем короткими и одинаковыми во всех состояниях.

**Проверка.** `npm test -- apps/web/src/analysis apps/web/src/demo`, `npm run check` и `npm run build`. Отправь SHA, пути и сценарии, которые проверил.
