# T51 · Интегратор · Слей ветки и доведи релизный SHA

Ты интегратор goida-code. Используй `release/cybergarden` от проверенного `main` после B00. Прочитай [ТЗ](../TZ.md) и [контракт](../CONTRACT.md). На входе четыре проверенных SHA · `feat/analysis`, `feat/api`, `feat/web`, `feat/deploy`.

1. Сверь общий базовый коммит и списки изменений. Слей последовательно analysis, API, Web и deploy. В каждом шаге сохраняй авторство коммитов. Конфликты разбирай по таблице владельцев. Если изменилась общая сигнатура, поправь контракт и всех потребителей в одном интеграционном коммите, прогони проверку заново.
2. Исполни `npm ci`, `npm run check`, `npm test` и `npm run build`. `check` и `build` работают в свежем checkout. Подними production `npm start`, затем `node deploy/smoke.mjs http://127.0.0.1:8787`. Проверь обе точки входа Web.
3. В `tests/e2e/**` добавь интеграционные сценарии Playwright Chromium по обязательным A1–A11 и A13. Fastify теста получает отдельный временный `MTS_DATA_DIR`, синтетический стартовый набор и тестовый токен. Настрой отдельный свободный порт, Web обслуживается из build. Для параллельных тестов используй независимый каталог и сервер или последовательное выполнение сценария, раннер прибирает дочерние процессы. Внешний провайдер тестируется локальным мок-сервером Responses API.
4. Тесты меняют файл на сервере атомарной записью и проверяют реальное изменение UI. Последовательность · `critical → assign → deadline → resolve`, затем сброс. Покрой двойное отображение одного ID, разовый toast, ход таймера, отключение SSE, сохранение данных на рестарте, битый файл, `Research` с завершением, скрытый сброс, резервный источник анализа, шторки и клавиатуру. Две страницы браузера получают одну правку одного файла.
5. Запусти `npx playwright install chromium` и `npm run test:e2e`. На Windows скрипты не требуют Bash. Создай `docs/mts/DEFENCE_LOG.md` с SHA, фактическими результатами, версиями окружения и таблицей A1–A13. Перечисли известные особенности эксплуатации и отдельно все нужные для T42 параметры.
6. Запиши релизный SHA для T42 и T52. Публикуй ветку через нормальный fast-forward или PR по правилам команды. Проверь, что артефакты сборки, выданные данные и секреты остались локальными.

**Приёмка.** API, Web, SSE, сборка и тесты проверены на одном точном SHA. Предоставь команду запуска, релизный SHA и статусы проверок.
