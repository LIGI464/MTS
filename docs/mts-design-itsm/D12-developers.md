# D12 · Тесты для разработчика

**Промт для Cursor, ветка UI.** Реализуй `DeveloperPage` в `apps/web/src/developers/**` и экспорт из `./developers`. Владелец D22 параллельно пишет другую страницу. Используй [контракт](CONTRACT.md) и [макет](DESIGN.md). Переход по адресу `/admin/developers` включит интегратор.

1. Покажи режим стенда, состояние источника, выбор активной заявки с её номером и статусом, поле токена и результаты последней операции. Токен живёт в памяти вкладки, передаётся в заголовке при записи. В режиме чтения доступно объяснение, как оператору включить сценарии. Автозапуск действий при открытии страницы исключён.
2. Сделай рабочие действия «Добавить критический», «Повысить приоритет», «Назначить координаторам», «Изменить срок», «Записать решение». После создания выбери возвращённый сервером номер. Другие действия применяются к явно выбранному ID. Перед решением нужен непустой текст. После подтверждённой записи отобрази ID, результат и переход в ITSM. Отдельно поддержи существующий подтверждаемый сброс: подпиши, что восстанавливает baseline, а история ITSM сохраняется.
3. При клике снимай версию с выбранной записи. На один пользовательский запрос создавай один UUID, повтор запроса после сетевого сбоя использует тот же ключ и то же тело. Заблокируй повторный клик в полёте. Ошибки 400/403/404/409 и обрыв соединения различимы. При конфликте перечитай запись и сохрани набранное решение. Показывай фактическое серверное подтверждение. Журнал действий за эту сессию содержит время и номер обращения.
4. Разработка при ещё не слитой D21 возможна по фикстурам в тесте. Для сдачи нажми кнопки на работающем Fastify и проверь изменение файла, кадр SSE во второй вкладке и одну заявку в реестре. В `dev:web` явно укажи ограничения автономной демонстрации. Остальные функции пульта продолжают работать.

**Сдать** отдельный коммит страницы, изменённые пути, состояние на телефоне, по одному верному и отклонённому действию с ожидаемыми надписями. Результат последующего интеграционного прогона по реальному серверу фиксирует D30.
