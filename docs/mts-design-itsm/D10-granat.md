# D10 · Библиотека МТС и тема

**Промт для Cursor, ветка UI.** Подключи источник дизайна МТС к рабочему React 19/Vite 7-приложению. Ты владеешь `apps/web/package.json`, общим `package-lock.json`, новой темой в `apps/web/src/styles/` и точкой подключения в `apps/web/src/main.tsx`. Форму темы возьми из [дизайна](DESIGN.md).

1. Проверь manifest/lockfile и материалы, доступные LIGI464. В рабочей базе `@mts/contracts`, `@mts/web` и `@mts/analysis` — локальные пакеты команды. Получи точное имя/версию Granat Web из выданного архива, registry или документации поставщика. Сверь издателя, экспорты, peerDependencies React, доступные стили и условия использования. Не угадывай название npm-пакета.
2. При доступном Web SDK установи в workspace `@mts/web` точную версию без `--force`. Импортируй поставляемую тему/шрифты и реальный компонент в основном входе приложения или в тонком адаптере, который используется на видимом экране. Дай минимум две проверяемые привязки к интерфейсу, например кнопка перехода и поле поиска, либо реально доступные аналоги. Сохрани lockfile и воспроизводимую установку для второго чата и CI. Доступ к закрытому registry задаётся вне Git.
3. Если выдали только Figma/токены, внедри официальный экспорт и иконки в пределах условий выдачи, сохрани ссылку/версию набора и перечисли применённые элементы. Явно различай «официальные токены» и «Web SDK». При отсутствии комплекта разметь компоненты и CSS-переменные по [DESIGN.md](DESIGN.md), используя действующие Radix/Lucide, оставь подключение заменяемым. Укажи одно конкретное недостающее вложение для менторов. Продолжай UI-блоки; полное требование Granat закрывается проверяемым импортом.
4. Определи роли `canvas/surface/text/muted/brand/focus/critical/warning/success`, табличную цифру и типографику с кириллицей. На каждой поверхности проверь обычный текст, фокус, disabled и ошибки. Для ссылок и кнопок выбери контрастную пару. В итоговом Web-бандле источник оформления должен работать в варианте поставки проекта.

**Сдать** видимый элемент на пульте, точный источник/версию и путь импорта или статус ожидания пакета, перечень фирменных элементов и локальных замен. Из чистой установки проходят `npm run check` и `npm run build`. Для закрытой зависимости опиши только название требуемой настройки сборки. Включать токен в образ, Git или `VITE_*` недопустимо.
