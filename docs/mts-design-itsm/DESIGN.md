# Экраны и дизайн-система

Момент, ради которого проектируется первый экран, — новое критическое обращение во время дежурства. Координатор должен сходу понять продукт, оставшееся время и кому передан инцидент. Из витрины МТС берём ритм шапки, светлую сетку, форму меню и контраст крупных секций. Содержимое всех рабочих элементов связано с инцидентами.

## Как применить четыре референса

| Вид на референсе | Как выглядит в пульте | Проверка |
|---|---|---|
| Белая двухрядная шапка, выпадающее белое мегаменю, затемнение фона | Верхний ряд компактный. Основные переходы — «Пульт», «Реестр ITSM», «Разработчикам». Из существующих шторок доступны разделы портала. В открытом меню слева — важные переходы, рядом — сгруппированные ссылки. В мобильной версии одна кнопка «Разделы». | Одновременно открыта одна шторка. Клик вне, Esc, Tab, возврат фокуса и переходы с клавиатуры работают. На touch открывается нажатием. |
| Светлый главный блок и компактные действия справа; белые карточки с крупным названием | Низкая сводка над очередями, слева «Пульт координатора», справа состояние данных и ссылка на реестр. В рядах карточек — номер, продукт, статус, команда и SLA. | При 1440×900 видны заголовки всех четырёх групп и первая карточка каждой непустой группы. При большом количестве заявок очередь открывается/прокручивается внутри предусмотренного списка. |
| Тёмная секция с карточками действий и переключателями | На странице разработчика тёмный блок акцентирует выбранный сценарий и результат. Под ним форма и журнал текущего прогона. Тёмную поверхность также можно использовать для компактной истории в ITSM. | Кнопки имеют конкретные названия. Карточки с действиями работают с клавиатуры. Основные действия доступны без горизонтальной карусели. |
| Светло-серый футер из колонок | Колонки «Пульт», «ITSM», «Разработка», «О проекте», существующий нижний каталог и прототипные ссылки. Текст команды — «goida-code · Кейс МТС». После футера остаётся свёрнутое «Служебное» с подтверждением сброса. | На телефоне длинные колонки сворачиваются. Есть точные ссылки на реестр и сценарии. После открытия шторки экран возвращается к прежней позиции. |

## Компоновка

| Элемент | На большом экране | На телефоне |
|---|---|---|
| Контейнер | Ориентир 1240 px по центру, боковые поля от 24 px, сетка на 12 колонок, интервалы 16–24 px | 1 колонка, поля 16 px, меню и карточки по ширине. От 768 px возможны две колонки по фактической вместимости |
| Шапка и сводка | Белая шапка, система/раздел слева, важные действия справа. Сводка остаётся компактной при 1280×720 | Короткое название и меню. Сводка переносится, статус соединения доступен текстом |
| Доска | Сетка 2×2: «Критические», «У координаторов», «Высокий приоритет», «Исследование». Число у заголовка соответствует именно группе | Последовательность групп та же. У фильтров и таблиц есть доступное представление без горизонтального скролла всей страницы |
| Детали / ИИ | Шторка или диалог с заголовком, номером, назначением, сроком, кнопкой ITSM, историей и отдельным запуском анализа | Полноэкранная панель с видимой кнопкой закрытия. Оповещения не накрывают форму |
| Реестр ITSM | Поиск, список с ID, продуктом, статусом и сведением о решении. В карточке две зоны: описание/решение и хронология | Записи превращаются в строки-карточки. Длинный номер, название команды и длинный текст решения переносятся |
| Разработчикам | Слева выбор сценария, справа целевой ID, параметры и результат. Для создания ID назначает сервер | Выбор, форма, результат последовательно. После отправки скринридер объявляет ID или ошибку |

## Тема и компоненты

Точные цвета, шрифты, радиусы и размеры официального комплекта берутся из его экспорта. Для промежуточной вёрстки ориентиры — белая поверхность, фон около `#F2F3F7`, тёмная секция около `#25273A`, фирменный красный акцент, заголовок 32–40 px, текст 14–16 px. Это параметры макета команды. В D10 сопоставить им реальные токены и начертания. Таймеры используют табличные цифры, все начертания проверяются на кириллице.

| Роль в интерфейсе | Что взять из доступной библиотеки МТС | Обязательные состояния |
|---|---|---|
| Действия и переходы | Основная/вторичная кнопка, иконка, текстовая ссылка. Одно главное действие на форму | default, hover, focus-visible, pressed, disabled, pending |
| Поиск и ввод | Поле, выбор, многострочное решение, подпись и ошибка рядом с полем | пустое значение, длинный текст, конфликт версии, неверный токен, повторить |
| Сигналы | Счётчик, индикатор связи, статус SLA и оповещения | актуально, переподключение, устаревший источник, «Срок не задан», близко, просрочен, решён |
| Навигация и поверхности | Тема, типографика, меню, диалог, вкладки, карта/поверхность; по существующим экспортам | открыто/закрыто, Tab и Esc, возврат фокуса, reduced motion |

Красный акцент используется для главного действия. Критическое состояние дополнительно имеет пиктограмму и явную подпись. Близкий срок получает янтарный маркер и текст, решённый инцидент — спокойный маркер с датой. Движение не нужно для чтения статуса. Иконка без текста получает доступное имя. Проверить видимый фокус, контраст текста 4.5:1, значимых иконок 3:1, масштаб браузера 200% и минимальную ширину 360 px. Оставить место для длинного русского названия без перекрытия SLA.
