# D00 · Общий старт

**Промт для Cursor.** Ты интегратор LIGI464. На одном ПК работают твой чат и Astra 6.2. Прочитай [порядок волн](README.md), [спецификацию](DESIGN.md) и [контракт](CONTRACT.md). За исходное состояние возьми текущий коммит ветки с этой папкой, содержащий рабочий релиз.

1. Проверь `git status --short --branch`, `git rev-parse HEAD`, `git merge-base --is-ancestor d23acbed7117f209c69716a79df31fdf5fd4cc28 HEAD`, `node -v`. Найди настоящий `App`, `IncidentBoard`, `useDashboard`, `createDashboardRuntime`, `normalizeIncidents`, `openDashboardStore` и `applyDemoStep`. Это точки подключения.
2. Выполни из корня `npm ci`, `npm run check`, `npm test`, `npm run build`. Для браузерной базы выполни `npx playwright install chromium` (если совместимый браузер уже подготовлен, используй его) и `npm run test:e2e`. Запиши отдельно пропуск необязательного теста локальной выгрузки, если файла на этом ПК нет. Не записывай фиктивный PASS.
3. Сверь первый экран `/admin/incidents` при 1440×900 и 390×844, детальную панель, состояние без внешнего ITSM-шаблона, сценарии CLI, сброс и ИИ. Отметь, что старая A8 закрепляет текст о ненастроенной ссылке. D30 заменит именно эту часть на реальный переход.
4. Дай LIGI464 две готовые команды для рабочих копий из README и два сообщения с **фактическим** SHA. Первое для Cursor — выполнить D10 в `design/ui`. Второе для Astra — выполнить D20 в `design/service`.

**Сдать** номер коммита, результаты четырёх проверок и Playwright, исходный размер/вид экрана, список локально доступных материалов Granat, две инструкции передачи задач. Приложение можно собирать на встроенных примерах. На этом шаге исходники приложения редактировать не требуется.
