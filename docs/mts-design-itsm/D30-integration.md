# D30 · Сборка и проверка

**Промт для интегратора LIGI464.** В `MTS-integration` получи точные SHA веток UI и сервера. Выполни обычное слияние обеих веток в `design/integration`, разрешая конфликты по назначению файлов. Возьми дизайн из [DESIGN.md](DESIGN.md), формы и сервер из [CONTRACT.md](CONTRACT.md). Работай с временным каталогом данных.

1. Соедини `AppShell`, `DeveloperPage`, `ItsmPage` и существующий пульт. Проверь явные маршруты, прямые ссылки после F5, мобильную навигацию, новую вкладку и выпуск статики через Fastify. Проверь GET неизвестного API: он должен возвращать JSON 404. Токен хранится только в памяти; каждому окну требуется свой ввод для записи.
2. Запусти `npm ci`, `npm run check`, `npm test`, `npm run build`, `npm run test:e2e`. Добавь e2e с двумя независимыми browser context одного экземпляра API. Оставь рабочее покрытие A1–A13. В A8 замени ожидание «ссылка не настроена» на настоящую эмулированную карточку с верным номером; сохрани проверку внешнего шаблона. В проверках SLA учитывай новый цвет темы вместе с подписью и актуализацией срока.
3. Подтверди рост количества записей при создании, один новый ID в реестре, ровно одно оповещение о каждом переходе, совпадение ID в двух группах, изменение именно выбранного дедлайна, сохранение решения и журнал после рестарта. Проверь ручную правку файла, в том числе только `solution`, битый JSON и восстановление. Повтор клика, неверный токен и конфликт версий не должны оставлять частичные данные.
4. Если LIGI464 дал оригиналы, импортируй в отдельный каталог и проверь 44 ID/решения и 5 Research. Не публикуй файл, его содержимое, операторский токен или ключ ИИ в PR. Rehearsal с искусственными данными и проверка оригинала должны быть различимы в отчёте. Снимки первого экрана проверить при 1440×900, 1280×720 и 390×844.
5. Зафиксируй, какие компоненты и токены Granat фактически включены в сборку, какой SHA тестировался и какие проверки прошли. Деплой на общий стенд — отдельная операция владельца после выбора версии.

**Сдать** интеграционный SHA, команды/результаты, список URL, подтверждённый режим Granat, найденные ограничения и ссылку на diff. При падении привести конкретную проверку и симптом, исправить в пределах вызвавшего её блока и повторить.
