# D00 · База и запуск в облаке

**Задание для облачного GPT, который имеет доступ к LIGI464/MTS.** Подними исходный пульт и проверь входные материалы. После этого выполни D10 → D20 → D30 → D40 в той же рабочей ветке.

## База

1. Открой LIGI464/MTS на ветке docs/dashboard-review-prompts. Фиксированная база стиля и исходного приложения — fix/dashboard-review на 5aa37dc9d81c391a865b01ed5453612e8b664b77. Зафиксируй SHA комплекта и фактический SHA своего начала. В неглубокой копии подтяни нужную историю из того же репозитория, если это требуется для проверки предка.
2. Начни реализацию в выделенной облаком рабочей ветке либо создай отдельную ветку от коммита комплекта. В следующих блоках продолжай результат предыдущего. Проверь git status и сохрани работу, уже присутствующую в рабочей копии.
3. Прочитай файлы инструкций репозитория, корневой README.md, [спецификацию](DESIGN.md) и все пять блоков. Для типографики и внешнего вида используй файлы этого коммита. Для целевого поведения руководствуйся D10, D20 и D30.

## Запуск и материалы

- Используй Node из engines в корневом package.json, для проверенной базы это Node 24. При необходимости установи зависимости командой npm ci, используя package-lock.json.
- Запусти npm run dev:web и открой локальный путь /admin/incidents. Для визуальной проверки начни с 1440×900. Сними или опиши исходную шапку, сетку, шрифты и состояние сводки.
- Проверь, что доступны apps/web/src/styles/theme.css, шесть файлов WOFF2 из apps/web/src/styles/fonts/ и команды для запуска и проверок в package.json.
- Открой [пустой пульт](references/dashboard-empty.png) и [пульт с уведомлениями](references/dashboard-unread.png). Если у среды есть только текстовый доступ к репозиторию, используй схему, подписи и таблицу состояний из DESIGN.md и D20.
- Для серверных и сквозных тестов используй data/demo/character_problems.json и временные копии тестового хранилища. Все сценарии можно проверить без рабочего ITSM, личного экспорта или доступа к стенду.
- Зафиксируй исходный результат npm run check. Если команда упала до изменений, запиши окружение и точную причину, чтобы отличить исходное состояние от регрессии. Продолжай с доступными проверками.
