# Пульт координатора · промты для облачного GPT

Пакет для репозитория LIGI464/MTS. Рабочая стилистика, компоненты и шрифты взяты из ветки fix/dashboard-review на коммите 5aa37dc9d81c391a865b01ed5453612e8b664b77. Два PNG показывают целевую компоновку и состояния уведомлений. Фирменная тема и все шесть WOFF2 уже входят в историю этой ветки.

## Стартовое сообщение для облачного GPT

> Открой LIGI464/MTS на ветке docs/dashboard-review-prompts. Прочитай docs/mts-dashboard-review/README.md и выполни D00 → D10 → D20 → D30 → D40 в одной рабочей ветке от этого комплекта. Для дизайна используй исходный пульт из fix/dashboard-review и референсы из docs/mts-dashboard-review/references/. Все материалы и тестовые данные есть в репозитории. Проверь результат и верни SHA, список изменений и отчёт по D40.

## Блоки

| Блок | Задание | Результат |
|---|---|---|
| [D00](D00-start.md) | База, запуск, входные материалы | Подтверждённый исходный SHA и рабочая ветка |
| [D10](D10-coordinator-itsm.md) | Координатор из JSON ITSM | Одно правило чтения и закрытый путь ручного назначения |
| [D20](D20-dashboard.md) | Компоновка сводки и очередей | Две карточки сводки, панель из пяти сегментов и шесть блоков очередей в два ряда |
| [D30](D30-unread-and-sound.md) | События, прокрутка и звук | Точные переходы, непросмотренность и ограничение звука по типу |
| [D40](D40-acceptance.md) | Приёмка | Результаты команд, два контрольных кадра и отчёт |

Каждый блок содержит команды и условия приёмки. В одном чате их можно передать одним стартовым сообщением. При разделении по сессиям указывайте текущую рабочую ветку и последний принятый SHA.

## Материалы внутри репозитория

- Два контрольных состояния, правила визуальной сверки и текстовая схема. В первом ряду очередей «Критические», «У координаторов», «Сроки». Во втором — высокий, средний и низкий приоритеты. [Спецификация](DESIGN.md)
- PNG без инцидентов с обоими рядами очередей. [Пустой пульт](references/dashboard-empty.png)
- PNG с непросмотренными инцидентами с обоими рядами очередей. [Пульт с уведомлениями](references/dashboard-unread.png)
- Тема, значок МТС и локальная типографика. [Тема](../../apps/web/src/styles/theme.css) · [Шрифты](../../apps/web/src/styles/fonts/) · [Логотип](../../apps/web/src/shell/mts-logo.svg)
- Тестовый JSON формы ITSM. [Демоданные](../../data/demo/character_problems.json)

Компоновку бери из этого пакета. Папка [mts-design-itsm](../mts-design-itsm/) служит образцом оформления промтов.
