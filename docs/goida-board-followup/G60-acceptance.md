# G60 · Итоговая приёмка

**Промпт для Cursor.** После G10–G50 проверь весь комплект на той же рабочей ветке. Запусти из корня `npm ci` при необходимости, `npm run check`, `npm test`, `npm run build` и `npm run test:e2e`. Используй существующие assistant-тесты API, тесты пакета analysis, `tests/e2e/d90-assistant.spec.ts` и браузерные сценарии операций. Проверь локальный режим и live через тестовый провайдер.

| Сценарий | Результат |
|---|---|
| Сводка в покое и при наведении | Серый параллелограмм появляется при наведении, счётчики и видимый фокус сохраняются |
| Длинные детали и открытый чат | Скролл внутри каждой панели, закрытие и поле отправки доступны |
| Допустимое оповещение и повтор | Звучит приложенный MP3 один раз, тихие категории и выключенный звук молчат |
| Медленная загрузка и тот же токен в A и B | Причина fallback подтверждена, готовый live-контекст обрабатывается в нужной карточке |
| Нерелевантные и реальные аналоги | Выдача совпадает с доказательствами, возможен ноль, ссылки открывают правильные записи |
| Первый анализ, обычный вопрос, явная просьба об аналогах | Карточки видны только в первом и явно запрошенном поиске, простой ответ короткий |
| Общее число просроченных из чата заявки | Число совпадает со сводкой на одном снимке, текущая заявка остаётся выбрана |
| Заметка и черновик от ИИ | После подтверждения сохраняются для нужного ID, исходные данные ITSM остаются прежними |

Сдай ветку и SHA, список файлов, фактические результаты команд, примеры коротких ответов и заметки, кадры интерфейса и подтверждение MP3. Отдельно обозначь непроведённые проверки с причинами. Остановись после отчёта.
