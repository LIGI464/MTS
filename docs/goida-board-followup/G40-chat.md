# G40 · Контекст чата, выдача аналогов и формат

**Промпт для Cursor.** Работай после G20 и G30. Точки входа — `apps/api/src/assistant/resolve.ts`, `index.ts`, общие схемы в `packages/contracts/src/assistant.ts`, `packages/analysis/src/assistant*.ts`, `apps/web/src/assistant/assistant-host.tsx`, `state.ts` и `assistant-panel.tsx`.

1. Различай первый автоматический анализ новой выбранной заявки, явную просьбу об аналогах и обычный вопрос. Начальный анализ однократно включает релевантные карточки. Повторное раскрытие чата восстанавливает переписку без второго начального анализа. «Скинь пожалуйста похожие проблемы», «найди аналоги» и равнозначные просьбы явно запускают выдачу аналогов. В обычном ответе поля карточек пусты, поиск аналогов не запускается ради скрытой выдачи. Используй явный признак намерения в контракте и проверяй это на сервере и в интерфейсе.
2. В режиме заявки сохрани её как контекст по умолчанию. Разреши вопросы о пульте и других доступных заявках. «Сколько у нас просроченных проблем?» получает число из того же актуального серверного снимка и правила SLA, что и сводка пульта. Другой явно указанный ID можно прочитать в пределах действующего уровня доступа. Укажи, о каком наборе данных ответ. При недоступности общего снимка сообщи об этом вместо подмены общего числа статусом одной заявки. Такой вопрос не должен сбрасывать выбранную заявку или прикладывать аналоги.
3. Формат для простого вопроса — прямой ответ одной или двумя строками. Для диагностики — короткие блоки «Кратко», «Что известно» и «Что проверить» с 1–3 конкретными пунктами. Блок «Похожие случаи» показывай по правилам пункта 1. Размечай блоки типизированными полями и отрисовывай читаемо. Гипотезу подписывай как гипотезу, а известное решение бери из записи. Избегай пересказа всех полей, лишних повторов и длинных вводных. Соблюдай тот же формат для live и локального ответа.

**Приёмка.** В чате открытой заявки спроси про весь просроченный набор и другую заявку, затем вернись к вопросу по текущей. Обычные ответы содержат ноль карточек. Явный запрос аналогов выводит только отобранные G30 записи. При смене заявки ответ из предыдущего запроса не попадает в новый чат.
