# Goida-board · правки интерфейса и помощника

База реализации — `release/goida-board`, SHA `0b6fe23007e5654631fe343016bbc9028d22f02b`. Ветка `docs/goida-board-followup` содержит ТЗ, промпты, визуальные референсы и оригинальный аудиофайл.

> Открой LIGI464/MTS и прочитай этот README на ветке docs/goida-board-followup. Для нового прогона создай ветку реализации от указанного SHA release/goida-board. Если стадия G10 уже принята, продолжай от её коммита в ветке реализации. После каждого блока покажи изменённые файлы, SHA и фактический результат проверок. Следующий блок бери только по моей команде.

| Блок | Результат |
|---|---|
| [G10](G10-interface-and-sound.md) | Мягкое серое наведение на нижней полосе, внутренний скролл деталей и оригинальный MP3 |
| [G20](G20-assistant-readiness.md) | Чат ждёт вопроса, диагностика переключения на локальные правила на ручном запросе |
| [G30](G30-matching.md) | Релевантные аналоги по исходной проблеме или выполненному решению |
| [G40](G40-chat.md) | Короткие ответы, сводка из чата заявки и аналоги по запросу |
| [G50](G50-notes.md) | Заметки в деталях и черновик от помощника |
| [G60](G60-acceptance.md) | Сквозная приёмка и отчёт |
