# D50 · Начало работы после D40

**Задание для облачного GPT в LIGI464/MTS.** Основа реализации — результат D10–D40, принятый владельцем проекта. Материалы этого задания и референсы лежат в ветке docs/assistant-analysis-prompts. Сначала прочитай [README](README.md), [визуальную спецификацию](DESIGN.md) и D60–D90.

## База и репозиторий

1. Возьми фактический SHA, переданный как принятый итог D40. Зафиксируй SHA в начале отчёта и создай рабочую ветку прямо от него. Ветка с промтами используется для чтения. Рабочий код берётся из принятого коммита.
2. Проверь состояние рабочей копии и существующие инструкции репозитория. Если предок результата D40 или документация недоступны из неглубокого клона, получи нужные объекты из LIGI464/MTS. Учитывай фактические пути и контракты принятой версии. Указатели на файлы в следующих блоках проверены по fix/dashboard-review и могут сдвинуться после D40.
3. Запусти команды базовой проверки из [D40](../mts-dashboard-review/D40-acceptance.md) для принятого SHA. Используй версию Node из package.json и npm ci при отсутствующих зависимостях. Зафиксируй ожидаемые результаты D40, включая группировку очередей, чтение координатора из ITSM и правила оповещений.
4. Сверь текущий «Пульт» и «Подробнее» с референсами. Открой локальный адрес /admin/incidents. Для первичной сверки интерфейса подходит npm run dev:web, для интеграции — штатный запуск с API и временной копией демоданных. Возьми тему, шрифты, значки и элементы управления из принятой ветки.

При двух рабочих деревьях документацию можно открыть в отдельной копии ветки. Пример для уже подключённого origin:

~~~bash
git fetch origin refs/heads/docs/assistant-analysis-prompts:refs/remotes/origin/docs/assistant-analysis-prompts
git worktree add --detach ../mts-assistant-docs origin/docs/assistant-analysis-prompts
~~~

## Порядок реализации

| Блок | Что проверить перед переходом дальше |
|---|---|
| [D60](D60-similar-incidents.md) | Поиск доказуемо работает по принятым архивным данным. Завершённые ID подтверждены исходными записями. |
| [D70](D70-assistant-api.md) | Чат получает результаты D60, возвращает короткие ответы и проверяемые ссылки. Проверки работают на репозиторных фикстурах. |
| [D80](D80-assistant-ui.md) | Постоянная кнопка и «ИИ-анализ» ведут в одну панель. Состояния соответствуют референсам. |
| [D90](D90-acceptance.md) | Выполнены интеграционные сценарии чата и повторены затронутые сценарии D40. |

В качестве тестовых источников используй data/demo/character_problems.json, имеющиеся фабрики и временные каталоги harness. Для проверки модели используй штатный локальный режим и существующий подход к мокам провайдера. Реальный экспорт ITSM и внешние учётные данные для приёмки не требуются.
