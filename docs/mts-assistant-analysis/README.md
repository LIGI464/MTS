# Помощник МТС · продолжение после D40

Комплект для облачного GPT с доступом к репозиторию LIGI464/MTS. Задача — чат «Помощник МТС» на «Пульте» и анализ выбранного инцидента с поиском похожих завершённых заявок в архиве ITSM.

Реализацию начинай от **принятого коммита D40**. Ветка docs/assistant-analysis-prompts хранит задания и согласованные референсы. [Комплект D00–D40](../mts-dashboard-review/README.md)

## Стартовое сообщение для облачного GPT

> Репозиторий LIGI464/MTS. Принятый результат D40 — коммит [SHA, полученный после приёмки]. Прочитай docs/mts-assistant-analysis/README.md из ветки docs/assistant-analysis-prompts. Создай рабочую ветку от принятого D40 и выполни D50 → D60 → D70 → D80 → D90. Используй код, референсы и тестовые данные этого репозитория. При завершении верни результаты команд, сценариев и SHA.

| Блок | Задание | Результат |
|---|---|---|
| [D50](D50-start.md) | База и порядок работ | Рабочая ветка от принятого D40 и проверенные точки входа |
| [D60](D60-similar-incidents.md) | Поиск в архиве ITSM | Похожие завершённые случаи по данным архива |
| [D70](D70-assistant-api.md) | Чат, ответы и ссылки | Типизированный API, краткие выжимки и ссылки на исходные заявки |
| [D80](D80-assistant-ui.md) | Интерфейс | Одна закреплённая кнопка и два режима чата, общий и с контекстом открытого инцидента |
| [D90](D90-acceptance.md) | Приёмка | Прогон сценариев чата и проверок D40, контрольные кадры и отчёт |
