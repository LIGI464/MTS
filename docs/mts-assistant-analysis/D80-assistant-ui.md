# D80 · Интерфейс «Помощника МТС»

**Задание для облачного GPT.** Продолжи работу в `LIGI464/MTS` в той же облачной ветке после D60 и D70. Собери интерфейс по утверждённым кадрам. Используй код, шрифты, референсы и тестовые записи из репозитория. Перед изменениями проверь сохранность рабочего пульта по D40. [Запуск и база](D50-start.md) · [Поиск похожих инцидентов](D60-similar-incidents.md) · [Контракт API](D70-assistant-api.md) · [Приёмка пульта](../mts-dashboard-review/D40-acceptance.md)

## Референсы

- При закрытом или свёрнутом чате кнопка «Помощник МТС» доступна в правом нижнем углу пульта. [Пульт без открытой карточки](references/00-dashboard-launcher.png)
- С пульта открывается только чат справа. В шапке нет выбранного инцидента, первое сообщение предлагает ввести номер или симптомы. [Общий чат](references/05-ai-assistant-general.png)
- При открытых деталях единственная кнопка запуска остаётся справа внизу поверх затемнения. Строка SLA содержит сведения об инциденте. [Детали до открытия чата](references/01-incident-assistant-launcher.png)
- При запуске из открытых деталей слева остаётся уже открытая карточка, справа виден чат с ней в качестве контекста. В переписке показаны похожие завершённые заявки со ссылками на ITSM. [Контекстный чат](references/02-ai-assistant-results.png)
- При сворачивании из шапки чат уходит вправо, детали возвращаются в обычное положение и нижняя кнопка снова появляется. [Свёрнутый чат](references/03-ai-assistant-collapsed.png) · [Открытие и сворачивание](references/04-ai-assistant-motion.gif)

## Одна кнопка, два контекста

1. На `/` и `/admin/incidents` отобрази единственную кнопку «Помощник МТС» с `position: fixed` справа внизу, пока чат закрыт или свёрнут. Кнопка доступна на первом кадре, при прокрутке пульта и деталей и при затемнении от деталей. При раскрытии чата скрывай кнопку визуально и исключай её из взаимодействия и порядка Tab. После сворачивания восстанавливай её в той же позиции.
2. Если на момент нажатия «Подробнее» закрыто, открывай только панель чата в режиме `dashboard`. На первом входе покажи локальное приглашение указать номер заявки или описать симптомы и жди отправки вопроса. Открытие не выбирает инцидент, не открывает «Подробнее» и не запускает запрос к API. В этом режиме пользователь может сам указать номер в чате. Ответ по введённому номеру отображается внутри чата.
3. Если при нажатии «Подробнее» уже открыто, используй режим `incident` с ID видимой карточки. Оставь открытой именно эту карточку, на широком экране сдвинь её влево для чата. В шапке чата покажи ID и краткий заголовок контекста. Доверенные факты для анализа получай через D70. Для нового диалога по этому ID запускай один начальный запрос на похожие случаи. Открытие «Подробнее» отдельно, без нажатия на помощника, само по себе не запускает чат.
4. Убери из деталей прежний элемент «ИИ-анализ» вместе с прежним встроенным интерфейсом анализа. Строка SLA сохраняет статус и время. Общий чат и диалоги выбранных инцидентов различаются по контексту. Повторное раскрытие восстанавливает черновик и сообщения текущего режима или ID. Возврат на пульт с закрытыми деталями открывает общий диалог без привязки из прошлого контекстного чата. Ответ, ожидавшийся для прежнего ID, не должен попасть в другой диалог.

## Компоновка и движение

1. Воспроизведи оформление из `apps/web/src/styles/theme.css` и локальные файлы `apps/web/src/styles/fonts/`. MTS Wide используется для заголовка чата и деталей, MTS Compact для интерфейса и кнопок, MTS Text для длинных сообщений. Светлые поверхности, обводка, скругления и красные акценты используют токены темы. Нижняя кнопка светлая, с красным знаком помощника, подписью «Помощник МТС» и компактным обозначением действия справа.
2. На широком экране закрепи чат у правого края на всю доступную высоту с обычными отступами от окна, как в референсе. Поле и отправка находятся внутри нижней части панели. Ширина около 30% окна. В кадре `1680×1040` это около `500px`. При открытых деталях их панель плавно сдвигается влево на ширину чата и межпанельный отступ, оставаясь читаемой. При сворачивании детали возвращаются в исходную позицию, а чат уходит за правый край. Используй текущую рамку деталей и один слой затемнения для открытой карточки.
3. Открытие идёт справа налево. Скрывай нижнюю кнопку при открытии и показывай её после сворачивания. Анимируй панели плавно без мигания или скачка разметки. При `prefers-reduced-motion` переход сразу принимает конечное положение. Быстрая смена действий «открыть → свернуть → открыть» приводит к последнему выбранному состоянию.
4. Если двум панелям недостаточно ширины, сохраняй читаемый чат в пределах окна и предсказуемый возврат к деталям при сворачивании. Учитывай динамическую высоту окна, safe area и экранную клавиатуру. Прокручивается история сообщений, а шапка, ввод и отправка остаются доступны. Проверь отсутствие горизонтальной прокрутки и перекрытия действующих контролов, включая закрытие деталей и управление оповещениями.

## Сообщения, статусы и ссылки

- В заголовке чата покажи «Помощник МТС». При входе из открытых деталей добавь рядом ID и краткий заголовок контекстной заявки. При обычном запуске с пульта поле вопроса и приглашение показываются без карточки контекста. Сообщение оператора отображай справа на светло-розовом фоне. Для готового ответа используй короткую сводку и карточки найденных записей. Поле ввода и кнопка «Отправить сообщение» остаются снизу.
- Подключи серверный `POST /api/v1/assistant/chat` по D70. Для `needs_context` покажи уточнение в переписке. Для `answer` отобрази текст, фактическое число результатов и возвращённые записи. Для каждой доступной записи покажи статус завершения, заголовок и «В ITSM» с ID. Дату, симптом и решение выводи при наличии подтверждённых данных. Ссылки открывают достоверную запись по штатному адресу ITSM или в реестре. Используй реальные доступные поля по контракту D60 и D70. ID, текст и число записей в PNG используются как примеры компоновки.
- Покажи ожидание ответа и возможность повтора после ошибки. При отсутствии результатов сообщи об этом в чате и оставь поле следующего вопроса. Подсказки под ответом используют тот же ввод и штатную отправку. Обработай длинные заголовки и текст без скачков ширины. Данные формы, ответы и ссылки выводи как обычный текст и безопасные ссылки, с обработкой состояний по D70.

## Точки интеграции и клавиатура

Найди в текущей рабочей копии `apps/web/src/main.tsx`, `apps/web/src/App.tsx`, `apps/web/src/board/incident-details.tsx` и `apps/web/src/styles/base.css`. Они задают маршруты пульта, владельца выбранных деталей, Radix Dialog и слои затемнения. Проверь `apps/web/src/analysis/analysis-panel.tsx` и вызов `runAnalysis` перед удалением прежнего входа из деталей. Остальные вызовы прежнего маршрута сохраняют свой контракт. Учитывай действующие права доступа. Проверь фильтры, очереди, оповещения, метку «Новый», переходы ITSM, историю заявки и чтение координатора из ITSM.

Согласуй слои и управление фокусом с Radix. При открытых деталях доступен элемент управления текущего состояния, включая состояние модального затемнения. Пока чат свёрнут, доступна нижняя кнопка, а при раскрытии — «Свернуть чат» в его шапке. При раскрытии переведи фокус в чат. При сворачивании верни его на вызвавшую кнопку, а если её нет, на восстановленную нижнюю кнопку. `Escape` сначала сворачивает чат, затем позволяет закрыть детали. Отрази состояния кнопок через `aria-expanded` и связь с панелью через `aria-controls`. Дай полю ввода и кнопкам понятные доступные имена. Скрытые поверхности исключи из порядка Tab.

## Проверка и передача дальше

На синтетических данных воспроизведи пять состояний PNG и движение GIF. Проверь `/` и `/admin/incidents`, прокрутку пульта и деталей, оба контекста одной кнопки, скрытие нижней кнопки в раскрытом чате и её возврат после сворачивания. Проверь запуск общего чата без деталей и запросов, один начальный запрос для выбранного ID, закрытие деталей после контекстного диалога, восстановление черновика, переключение между заявками и возврат фокуса. Сверь кадры на `1680×1040` и проверь рабочие размеры `1440×900`, `1280×720`, `390×844`, включая клавиатуру и сокращённое движение. Используй зафиксированные в репозитории тестовые данные и штатные команды проверок. Сохрани результат в рабочей ветке и передай SHA, изменённые файлы, фактические проверки и кадры для D90.
